Что такое Nexus Prime Bot?

Nexus Prime Bot — это современный Discord-бот нового поколения, созданный для обеспечения максимального контроля и автоматизации вашего сервера. С интеллектуальной системой владельца, автономным запуском и автоматическими обновлениями.

Как начать

Простая установка за 4 шага

1

Клонируйте репозиторий

git clone https://github.com/VovaLoV/Nexus-Prime-Bot.git
2

Установите Python

Убедитесь, что у вас установлен Python 3.8 или выше

python --version
3

Запустите launcher.py

Launcher автоматически установит все зависимости

python launcher.py
4

Настройте токен

Введите токен вашего Discord бота при первом запуске

nexus_config.json
Перейти на GitHub Discord
