# Nexus Prime Bot v1.3.2 (Beta)

Discord-бот для управления мультивселенной Нексус Прайм

## Особенности:
- Автономный запуск с launcher.py
- Авто-обновление с GitHub
- Диагностика системы
- Управление мирами (Нео-Вольфград, Лунная Долина, Этерия, Космос)
- Система паспортов
- Управление кораблями
- Интеграция с Ollama AI

## Установка:
1. git clone https://github.com/VovaLoV2024/nexus-prime-bot.git
2. cd nexus-prime-bot
3. python launcher.py

## Требования:
- Python 3.8+
- Discord.py
- Colorama

## Структура:
- launcher.py - главный файл запуска
- nexus_bot.py - основной бот
- nexus_setup.py - настройка сервера
- nexus_config.json - конфигурация
