# Nexus Prime Bot v1.4.0 (Beta)

Discord-бот для управления мультивселенной Нексус Прайм

## Особенности:
- Автономный запуск с launcher.py
- Авто-обновление с GitHub
- Диагностика системы
- Умная система владельца

## Установка:
1. `git clone https://github.com/VovaLoV2024/nexus-prime-bot.git`
2. `cd nexus-prime-bot`
3. `python launcher.py`

## Требования:
- Python 3.8+
- Discord.py
- Colorama

## Структура:
- `launcher.py` - главный файл (в корне)
- `nexus_core/` - папка с файлами бота
  - `nexus_bot.py` - основной бот
  - `nexus_config.json` - конфиг (не загружать на GitHub!)
  - `VERSION.txt` - версии

## Команды:
- `!помощь` / `!commands` - список команд
- `!пинг` - проверить пинг
- `!инфо` - информация о боте
- `!сервер` - информация о сервере
- `!прайм` - установить владельца
- `!статус` - показать статус
